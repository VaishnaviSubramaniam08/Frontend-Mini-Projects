# 🚀 Frontend Mini Projects

A collection of simple and useful frontend applications built with HTML, CSS, and Vanilla JavaScript.

## 📂 Projects Included

### 1. [Notes Taking App](./notes_app/)
A simple notes app to create and delete notes. Uses dynamic DOM manipulation.

### 2. [Todo List App](./todo_app/)
A task management app to add, complete, and delete tasks. Features strike-through for completed items.

### 3. [Calculator App](./calculator_app/)
A responsive calculator for basic arithmetic operations. Built using CSS Grid and JavaScript.

### 4. [Digital Clock](./digital_clock/)
A simple digital clock with date display and a dark mode toggle.

---

## 🛠️ How to Run

Each project is independent. To run any of them:
1. Navigate to the project folder (e.g., `cd todo_app`).
2. Open `index.html` in your browser.
