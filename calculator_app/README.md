# 🔢 Calculator App

A simple and responsive Calculator application built using HTML, CSS, and Vanilla JavaScript.

This application performs basic arithmetic operations with a clean and intuitive user interface.

---

## 🚀 Features

- Basic Arithmetic: Addition, Subtraction, Multiplication, Division
- Percentage calculation
- Delete single character functionality
- Clear display functionality
- Error handling for invalid expressions
- Responsive Grid-based layout
- Modern and clean UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid Layout)
- JavaScript (Vanilla JS)

## ⚙️ How It Works

1. Buttons use `onclick` events to trigger JavaScript functions.
2. `appendValue()` adds numbers and operators to the display.
3. `calculate()` uses the `eval()` function to evaluate the mathematical expression.
4. `deleteLast()` removes the last character using string slicing.
5. `clearDisplay()` resets the input field.

---

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the `calculator_app` folder.
3. Run `index.html` in your browser.
