# Digital Clock

A simple, interactive digital clock web application.

## Features

- **Real-time Clock**: Displays current time in HH:MM:SS format.
- **Date Display**: Shows the current day of the week, month, and date.
- **Dark Mode**: Includes a toggle button to switch between light and dark themes.

## Technologies Used

- **HTML5**: Structure of the application.
- **CSS3**: Styling and responsive design.
- **JavaScript**: Time logic and theme switching functionality.

## How to Run

1. Open `index.html` in any modern web browser.
2. Use the "Toggle Dark Mode" button to switch themes.
