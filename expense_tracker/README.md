# 💰 Expense Tracker

A simple and intuitive application to track your income and expenses, helping you manage your finances effectively.

## ✨ Features

- **Transaction Tracking**: Add transactions with a title, amount, and category (Income or Expense).
- **Balance Overview**: Real-time display of your total balance, total income, and total expenses.
- **Data Visualization**: A dynamic pie chart (powered by Chart.js) that visualizes your income vs. expense ratio.
- **Persistence**: Your transactions are saved in `localStorage`, so your data remains even after refreshing the page.
- **Delete Functionality**: Easily remove incorrect or old transactions.

## 🛠️ Technologies Used

- **HTML5**: For the structure.
- **CSS3**: For custom styling and layout.
- **JavaScript (ES6)**: For core logic and DOM manipulation.
- **Chart.js**: For generating the visual pie chart.

## 🚀 How to Use

1. Open `index.html` in any modern web browser.
2. Enter the transaction title and amount.
3. Select the type (Income or Expense).
4. Click "Add Transaction" to update your list and chart.
5. Use the "X" button next to any transaction to delete it.
