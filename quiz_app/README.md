# 🧠 Quiz App

A simple and interactive Quiz Application built using HTML, CSS, and Vanilla JavaScript.

This project features a timed quiz with real-time scoring and instant feedback on answers.

---

## 🚀 Features

- Multiple choice questions
- 15-second timer per question
- Real-time score tracking
- Instant feedback (Correct/Wrong)
- Final result display
- Clean and responsive UI
- Dynamic question loading

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## ⚙️ How It Works

1. The quiz loads a question and starts a 15-second timer.
2. The user selects an answer from the options.
3. If correct, the option turns green and the score increases.
4. If wrong, the selected option turns red and the correct answer is highlighted.
5. If the timer runs out, the options are disabled and the correct answer is shown.
6. The user clicks "Next Question" to proceed.
7. After the last question, the final score is displayed.
