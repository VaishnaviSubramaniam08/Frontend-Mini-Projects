# 🧩 Sudoku Game

A classic Sudoku puzzle game built for the browser. Test your logic and speed!

## ✨ Features

- **Interactive Board**: A clean 9x9 grid with pre-filled numbers and user-input cells.
- **Real-time Validation**: Highlights invalid moves if a number already exists in the same row or column.
- **Timer**: Tracks how long it takes you to solve the puzzle.
- **Reset Functionality**: Quickly clear your progress and restart the game with a single click.
- **Win Detection**: Notifies you once you've successfully completed the puzzle correctly.

## 🛠️ Technologies Used

- **HTML5**: For the game structure.
- **CSS3**: For the grid layout and responsive design.
- **JavaScript (ES6)**: For game logic, timer, and validation.

## 🚀 How to Play

1. Open `index.html` in your browser.
2. Fill in the empty cells with numbers from 1 to 9.
3. Ensure each number appears only once in every row and column.
4. If a cell turns red, it means there is a conflict in that row or column.
5. Solve the entire grid to win the game!
