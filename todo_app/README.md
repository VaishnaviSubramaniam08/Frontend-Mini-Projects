# 📝 Todo App

A simple and efficient Todo List Application built using HTML, CSS, and Vanilla JavaScript.

This project allows users to manage their daily tasks by adding, completing, and deleting them with ease.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed (strike-through)
- Delete tasks
- Responsive design
- Clean and modern UI
- Persistent interaction via DOM

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Font Awesome (for icons)

## ⚙️ How It Works

1. User enters a task in the input field.
2. Clicking the "Add Task" button appends the task to the list.
3. Each task has a checkbox to mark it as completed.
4. Each task has a delete button (trash icon) to remove it from the list.

---

## ▶️ How to Run the Project

1. Download or clone the repository.
2. Open the `todo_app` folder.
3. Run `index.html` in your browser.
